# Catalog data sources and reuse

## BLS 4.0 food composition release

The catalog imports the official German-language BLS 4.0 release from the Max Rubner-Institut (MRI), not a secondary nutrition table:

- Dataset: [Bundeslebensmittelschlüssel (BLS) 4.0](https://doi.org/10.25826/Data20251217-134202-0), release `BLS_4_0_2025_DE` (December 2025).
- Recommended citation in the supplied documentation (§9.2): Max Rubner-Institut (2025): *Bundeslebensmittelschlüssel (BLS), Version 4.0*. Karlsruhe. The importer attribution also includes the DOI.
- Rights: the supplied documentation (§1.2 and §9.3) states that BLS 4.0 is provided without license barriers and may be used for research, nutrition planning, and app/software development. The validated release metadata records `CC BY 4.0`; retain the MRI attribution and dataset DOI. The source package is not embedded in application code.
- Basis: the BLS 4.0 documentation, §2.1 p. 5, states that nutrient values are per 100 g edible portion; §7.2 p. 22 clarifies that inedible parts (such as peel or pits) are already excluded. Imported food versions therefore explicitly store `nutrient_basis='edible'`. Portion scaling remains disabled for versions whose persisted basis is not `edible`.
- Provenance: each source value retains its component code, raw cell marker, source method, source reference, normalized numeric value when available, and an explicit status. Numeric zero is distinct from dash/blank missing, trace, below-LOD, below-LOQ, and unsupported mapping. The source release is immutable and identified by its archive SHA-256.

The validated archive is `.data/BLS_4_0_2025_DE.zip`, SHA-256 `12b7a6ba62807ec9b301eb276f897dc85f99b2292311618dec3749a12d984c91`. It contains the data workbook, component reference workbook, and German documentation PDF. Validation of the downloaded archive read **7,140 foods, 138 components, 418 headers, and 985,320 nutrient cells** with no duplicate food codes, negative values, or unknown raw markers. All 418 headers were mapped to their adjacent value/method/reference columns. Counts by cell interpretation: 656,320 nonzero numeric; 213,181 explicit numeric zero; 110,083 dash missing; 59 blank missing; 746 below LOQ; 2,733 below LOD; 392 below LOD-or-LOQ; 1,806 trace. These counts are from the generated validation report `scripts/import-bls/reports/BLS_4_0_2025_DE.json`; validation is not a database import or publication.

The documentation confirms 7,140 foods and 138 components (§2.1 p. 5); the component workbook supplies all definitions (§6.1 p. 21). The full archive was revalidated against the shared domain/importer crosswalk: 24 components map to canonical definitions; 114 retain their source definitions, codes, values and provenance without guessed canonical semantics. The component workbook identifies dietary fibre (`FIBT`, g), vitamin D (`VITD`, µg), alpha-tocopherol (`VITE`, mg), B12 (`VITB12`, µg), C (`VITC`, mg), calcium (`CA`, mg) and magnesium (`MG`, mg). `VITE = TOCPHA` is alpha-tocopherol, not alpha-TE; the duplicate component is not added twice. The official folate formula (§5.7 p. 19) is `FOL = FOLFD + 1.7 × FOLAC`; `FOL` remains `folate_blsequiv`, distinct from EFSA DFE and its separately retained components.

The documentation notes that its editorial preparation was AI-assisted and reviewed by MRI scientific staff (§1.1 p. 4). It is data-source documentation, not an EFSA health recommendation. No BLS documentation prose or tables are copied into the UI.

## Catalog display hierarchy and external BLS groups

The catalog combines a versioned app-owned navigation tree with distinct BLS source-group category records. `supper-board-display-v1` provides 11 display roots; 20 documented BLS source groups remain separately coded and labeled child nodes at `bls4-source-groups-v1`. The external labels/codes and each food row's `food_categories.source_category_code` preserve the BLS identity; adding display parents does not rewrite immutable food-category assignments or nutrient data. The unknown `?` source group remains visible at the root as “Noch nicht zugeordnet.”

This explicit crosswalk is intentionally coarse: BLS source groups are mixed editorial groups, not a per-food ontology, so the full external label stays visible at the child node rather than implying a reviewed food-by-food classification.

Crosswalk choices follow the official group label and do not claim fine-grained classification within mixed groups. Tags remain independent of category ancestry.

## EFSA standard-adult reference source packet

These rows are a source/evidence packet for the EFSA rows in `IMPLEMENTATION_ROADMAP.md` §8.5, not clinical guidance or individualized targets. Preserve the source’s value type, unit, denominator, chemical form, cohort, and basis. In particular, do not turn an energy percentage into grams without an explicitly selected energy value, do not derive a daily protein amount without body weight, and do not treat sodium’s safe-and-adequate value as a minimum target. The independent decision/status record is [`REFERENCE_REVIEW.md`](./REFERENCE_REVIEW.md); this packet does not activate references.
